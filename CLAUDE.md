# Sniper Agent — контекст проекта

Мониторинг твитов крипто-инфлюенсеров (KOL) → извлечение адреса контракта
нового токена → алерт в Telegram.

## Стек
Python 3.12, FastAPI (приём вебхука), aiogram 3 (Telegram), Redis (дедуп),
httpx, Docker Compose. Источник твитов — twitterapi.io.

## Поток данных
twitterapi.io stream → webhook (app/main.py) → Pipeline (app/pipeline.py)
→ parser (app/parser.py) → dedup (app/dedup.py) → notifier (app/notifier.py)

## Что требует проверки в первую очередь
1. `normalize_tweet()` в app/providers/twitterapi_io.py — имена полей взяты
   из документации, а не из живого ответа. Сверить и поправить.
2. Путь эндпоинта регистрации стрима в `register_stream()`.
3. Сборка и запуск docker compose.

## Чего в этапе 1 намеренно нет
Обогащения данных (капитализация, ликвидность, холдеры), rug-чеков,
Postgres, подсчёта трек-рекорда KOL. Это этап 2.

## Правила работы
- `.env` в гит не коммитим никогда.
- Ключевая метрика — `Tweet.latency_seconds` (время от публикации твита до
  получения). Цель — единицы секунд. Не ломать её оптимизациями.
- Парсер покрыт тестами (tests/test_parser.py). Любая правка регулярок или
  денилиста — сначала тест, потом код.
- base58 реализован вручную в parser.py, чтобы тесты гонялись без
  зависимостей. Не заменять на внешнюю библиотеку без причины.
